# Fonts

The typefaces both Tawam apps ship with. All are IBM Plex, under the
[SIL Open Font License 1.1](https://openfontlicense.org) (`OFL-IBMPlex.txt`).

| File | Family | Used for |
|---|---|---|
| `IBMPlexSans.ttf` | IBM Plex Sans (variable) | All text |
| `IBMPlexSansArabic-*.ttf` | IBM Plex Sans Arabic | Arabic text |
| `IBMPlexMono-*.ttf` | IBM Plex Mono | Pairing codes, IDs |

Taken unmodified from [google/fonts](https://github.com/google/fonts)
(`ofl/ibmplexsans`, `ofl/ibmplexsansarabic`, `ofl/ibmplexmono`).
